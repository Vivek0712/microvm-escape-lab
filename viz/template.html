What the audit caught — and what hardening the adversary revealed

Exec bypass: blocked from read_file, the agent read files through an allowlisted program (cat /proc/1/environ). The policy only checked the program name; it now applies the file-path allowlist to exec arguments too.

The stronger adversary paid off: adding DNS tunnelling, interpreter breakout, and path-traversal exposed that the microVM boundary alone does not stop egress — the loose cage (A) exfiltrates over dns_query. Strands Box blocks DNS, canonicalizes paths (so /work/../etc/passwd can't sneak past), and denies python3 -c that reaches the OS — denying 44 of 49 actions.

ECScape defeated by design: the cross-container IAM hijack (Black Hat 2025) needs a shared host; per-VM isolation means the metadata service only ever serves this VM's own least-privilege role.
